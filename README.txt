AURI — ARTIST WEBSITE

Откройте index.html в браузере или через Live Server в VS Code.

В комплекте:
- index.html — весь сайт на одной странице;
- style.css — дизайн и адаптивность;
- script.js — анимации, свайп галереи и просмотр работ;
- images/ — 24 исходных арта.

Галерея не обрезает изображения: каждый арт отображается с сохранением исходных пропорций.
Можно перетаскивать галерею мышкой, свайпать на телефоне и открывать работы на весь экран.
